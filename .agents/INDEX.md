## Rutas Críticas de Producto

- [`rules_pattern_making.md`](file:///d:/AGUSTIN/Portafolio/Proyectos/Proyecto%20App%20-%20Generador%20de%20Patrones/rules_pattern_making.md): Reglas de patronaje técnico textil inyectadas al LLM.
- [`start_web_studio.bat`](file:///d:/AGUSTIN/Portafolio/Proyectos/Proyecto%20App%20-%20Generador%20de%20Patrones/start_web_studio.bat): Launcher de 1 clic con build automático y servicio en puerto 3030.
- `scripts/`: Scripts de prueba y automatización:
  - `test_fireworks_call.js`: Diagnóstico de conectividad con Fireworks AI (Qwen 3.8 Max).
  - `test_fireworks_e2e_image.js`: Verificación E2E de pipeline por imagen.
  - `test_blender_export.js`: Validación de archivos `.glb` glTF 2.0 y materiales PBR.
  - `export_glb_headless.py`: Script Python para Blender CLI headless.
- `src/index.ts`: Entrypoint del CLI y subcomandos (`generate`, `bundle`, `serve`, `export-3d`).
- `src/pipeline.ts`: Orquestador principal del pipeline end-to-end (2D + 3D + Bundling).
- `src/ai/`: Proveedores de IA (`DirectApiProvider` para Fireworks AI, `MockAiProvider`, `PromptBuilder`, `AiProviderFactory`).
- `src/schema/`: Esquema Zod y validador de ADN paramétrico (`pattern_schema.ts`).
- `src/engine/`: Motor geométrico FreeSewing v3 (`base_blocks/`, `modifier.ts`, `exporter.ts`, `tech_sheet.ts`, `etsy_bundler.ts`, `blender_bridge.ts`, `triangulator.ts`).
- `src/utils/tiler.ts`: Motor de corte y paginado vectorial A4/Letter con cruces de ensamble y cuadro 10x10cm.
- `src/server/`: Servidor HTTP REST y frontend Web Studio (HTML, CSS, JS, Visor 2D, Visor 3D WebGL con Exploded View Slider).
- `output/`: Entregables físicos generados (PDFs, SVGs, Modelos .glb 3D, Fichas técnicas y paquetes comerciales ZIP).
